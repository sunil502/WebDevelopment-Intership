# Week 4 – Student Management Dashboard

## 🌐 Web Development Internship – Major Project

This project is the **Week 4 Major Project (Capstone)** of my Web Development Internship.

The project is a complete **Student Management Dashboard** built using HTML, CSS and JavaScript.

The application demonstrates CRUD operations, localStorage, DOM manipulation, searching, filtering and responsive UI design.

---

# 🎯 Project Objective

The objective of this project is to build a practical frontend application that allows users to manage student records.

The application supports:

- Add student
- Edit student
- Delete student
- Search students
- Filter students
- Store student data using localStorage
- Display student records in a table
- Show dashboard statistics
