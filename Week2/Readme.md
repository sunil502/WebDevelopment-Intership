# Week 2 – Interactive Web Projects

## 📌 Overview

This project is part of the **Web Development Internship – Week 2 Assignment**.

The main objective of Week 2 is to learn **CSS styling, animations, JavaScript, DOM manipulation, event handling, and real-time updates** by building interactive web projects.

This week includes:

1. 🖼️ Interactive Image Gallery
2. 🕐 Digital Clock
3. ⏳ Countdown Timer

---

## 🎯 Objectives

- Learn JavaScript fundamentals
- Understand DOM manipulation
- Handle user events using JavaScript
- Create interactive UI components
- Work with JavaScript `Date()` object
- Use `setInterval()` for real-time updates
- Create CSS hover animations
- Implement a lightbox image gallery
- Improve responsive web design

---

# 🖼️ Assignment 1 – Interactive Image Gallery

## 📌 Description

An interactive image gallery containing multiple images displayed in a responsive grid.

Users can click on any image to open it in a **lightbox view**.

The gallery also provides:

- Previous button
- Next button
- Close button
- Image hover animation
- Keyboard navigation
- Responsive layout

---

## ✨ Gallery Features

- 8 images displayed in a grid
- Hover zoom animation
- Click an image to open the lightbox
- Previous and Next navigation
- Close lightbox
- Click outside the image to close
- Press `ESC` to close
- Press `←` for previous image
- Press `→` for next image
- Responsive design
